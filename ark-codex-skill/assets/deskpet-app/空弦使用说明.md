# 空弦「至虔者荣光」桌宠

需要Windows 10/11和Python 3.10或更高版本，首次安装需要网络。

1. 解压下载包，保留整个目录结构。
2. 双击「安装环境.bat」，在当前目录创建独立`.venv`并安装PySide6。
3. 双击「启动桌宠.bat」。之后启动不需要重新安装环境。

下载包包含桌宠代码、5种动作的337张透明PNG帧、循环区间及9张已包含在帧数中的过渡帧，还有5份原始WebM。它不包含虚拟环境、会话日志、个人窗口位置或开机启动配置。

- 单击播放互动动作，双击切换迷你模式。
- 右键选择放松、坐下、睡觉，或打开设置。
- 英文字体为Times New Roman，中文为宋体，字号范围6–26px。
- 字幕居中，超出宽度时滚动显示，白字带细描边，无色块背景。
- 已处理放松、移动、坐下、睡觉的循环接缝。互动保持原始单次播放。

素材来源为[PRTS的空弦页面](https://prts.wiki/w/空弦)，皮肤为「至虔者荣光」，模型组为基建。原始WebM保存在`pets/空弦/webm/`。本次导出解码后没有有效透明通道，透明PNG由移除与画布边缘相连的黑色背景得到，极暗边缘可能与原模型略有差异。

状态监视器读取`~/.codex/sessions/`下最后更新的会话日志，不会汇总并行会话；超过8秒没有日志更新时会显示待机。
